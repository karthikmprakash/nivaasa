# Nivaasa v1.0.4 — small correctness patch

A short follow-up to v1.0.3 for a few edge cases found during the production smoke test.

## Fixes

- **The admin attention total now counts every SLA-risk request.** Previously a stack of requests approaching or past their deadline was counted as a single item, so the greeting and “Needs attention” card under-reported the workload.
- **The admin greeting is correct after midnight.** The hour is read on a strict 24-hour clock, so early-morning sign-ins no longer say “Good evening”.
- **Overnight full-day amenities can be created.** A space that opens at 12:00 and closes at 11:00 the next day is valid when its slot length is 24 hours, matching the seeded Guest Suite.
- **Offline payment dates are validated in IST.** Impossible calendar dates are rejected, and a valid date is stored at Asia/Kolkata midnight rather than UTC midnight.
- **Billing notices only go to homes.** Team memberships without a linked unit no longer receive a resident billing notification that leads to a page they cannot open.

## Database

No schema changes. The Docker entrypoint still runs `npm run db:push` before starting the app, and an existing data volume is preserved.
