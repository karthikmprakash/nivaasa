# Nivaasa v1.0.0 — the blue mark

The first public Nivaasa release: a complete, self-hosted community operating system with a new identity built around the Kannada word **ನಿವಾಸ** — *the place we live*.

## Highlights

- **New brand system.** The Kannada syllable **ನಿ** with a lit window, a blue app tile, a bilingual **ನಿವಾಸ / nivaasa** lockup, icon set and a full logo pack.
- **Motion.** A blue-tile mark that writes itself, a seamless window loop, a compact mark reveal and a success check — all with alpha WebP/HEVC and reduced-motion fallbacks.
- **Refreshed product UX.** Flatter surfaces, sharper hierarchy, calmer navigation and a consistent blue/white/blush language across the resident, admin, guard, onboarding, login and portfolio surfaces.
- **The full product.** Gate and visitor management, deliveries, helpdesk, amenities, maintenance billing, accounting, notices, polls, events, discussions, classifieds, directory, documents, staff, vendors, assets, audit logs and an emergency flow.
- **Demo community included.** Verdant Heights and Lakeview, seeded with residents, invoices, payments, tickets, visitors and history.

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · Drizzle ORM + SQLite · Expo 58 for the resident/guard app.

## Container

```bash
docker pull ghcr.io/karthikmprakash/nivaasa:1.0.0
```

The image runs the schema check on boot and seeds the demo only when the database volume is empty. See [the Dokploy runbook](https://github.com/karthikmprakash/nivaasa/blob/main/docs/deploy-dokploy.md) for the Dokploy/GHCR runbook.

## Self-host

```bash
docker compose up --build
```

Or use the production compose:

```bash
docker compose -f docker-compose.dokploy.yml up -d
```

## Notes

- Payments are simulated until a gateway is connected.
- SQLite is the default; the Drizzle schema is ready for a Postgres adapter.
- The mobile app is included in the repository; the web console is the complete admin surface.
