# Nivaasa v1.0.5 — account menu icon alignment

A one-line visual fix for the account menu.

## Fix

- **All account-menu icons now render at 16px.** The Settings gear was using Lucide’s default 24px while the society, home, emergency, portfolio and sign-out icons used 16px, which made the gear look oversized.
- **Society icons now inherit the same colour as the other menu icons.** They no longer use the muted text colour, so the menu reads as one consistent icon set.

Both the resident menu (My home / Settings / Emergency) and the admin menu (Society settings) are covered.

## Database

No schema changes.
